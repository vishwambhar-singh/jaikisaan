# JaiKisaan Solar — Precision Solar Engineering

A modern, high-performance responsive web platform for **JaiKisaan Solar** (SunScope Group), engineered with React 18, TypeScript, TailwindCSS, and Vite.

## Live Demo
- **GitHub Pages:** [https://vishwambhar-singh.github.io/jaikisaan/](https://vishwambhar-singh.github.io/jaikisaan/)

## Features
- **Design Tokens & Brand:** Precise implementation of JaiKisaan Solar design system (`#005733` forest green, `#C5F176` lime, `#17231D` dark).
- **Responsive Engineering:** Fluid layouts optimized for mobile devices (320px–414px) through large 4K displays.
- **Dynamic City Hubs:** 5-state multi-hub operational selector (Lucknow, Jaipur, Bhopal, Chandigarh, New Delhi) with localized solar metrics, team context, and subsidy guidance.
- **Solar Feasibility Calculator:** Interactive rooftop and commercial load estimator with instant subsidy calculations.
- **Complete Suite:**
  - Precision Home Hero & Architecture
  - Solutions Showcase (Residential, Commercial, Agricultural)
  - Projects & Case Studies
  - Multi-hub Contact & Telemetry mesh
  - Knowledge Hub & Blog
  - Design Tokens & Foundation Specification

## Tech Stack
- **Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [TailwindCSS](https://tailwindcss.com/)
- **Routing:** [React Router v6](https://reactrouter.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/vishwambhar-singh/jaikisaan.git
cd jaikisaan

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
